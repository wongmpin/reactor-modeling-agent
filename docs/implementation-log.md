用户明确确认甲烷100000t/a、8000h/a，即12500kg/h，进料/出口13.5bar、PR/HYSYS数据库、五物种且无固碳、出口710/600°C。模型最初将甲烷支路摩尔流误填混合总流量；复核发现后新增component_mass_flows_kg_h独立约束，Adapter按HYSYS数据库分子量与组成推算总流量并独立核验支路质量流。两种工况已按修正规格6/7真实重跑，原错误总量运行4/5标记validation_failed并保留审计。

修复后全套54项测试通过，含8项实机测试；新增混合流量与支路流量区别、未知确认键、缺参禁用提交及显式确认交互回归。

## DeepSeek SSE流式回复

DeepSeek conversation请求使用OpenAI兼容SDK的`stream=True`读取SSE事件；服务端逐段提取JSON对象的reply字符串，同时缓冲并校验完整JSON/action。Streamlit通过占位容器把累积文本增量推送到聊天气泡，不用阻塞至整段回复完成。协议无效/流异常仍返回错误诊断，不将部分文本保存为完成回复。实测在线中文回复269段，首段约2.79秒，拼接流与完整校验后的回复完全一致；普通测试覆盖JSON转义、分块边界、完整性和stream请求参数。Streamlit浏览器通道本身是原生WebSocket，不宣称浏览器端连接是SSE。
