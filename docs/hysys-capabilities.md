# HYSYS V15 能力与真实验证

日期：2026-10-25。Windows 本机 COM ProgID `HYSYS.Application` → `HYSYS.Application.V15.0`，返回 `Aspen HYSYS Version 15 (41.0)`。

## 已验证

- 通过独立 STA Worker 连接/读取版本；从空案例建立组分列表、PR物性包、物流和反应器。
- `PengRob` 是内部物性包标识；`ConversionRxn`、`ConversionReactorOp`、`GibbsReactorOp` 是实测可用类型。结束 `BasisManager.EndBasisChange()` 后配置物流。
- Conversion：显式气相、基准组分、单反应计量、给定转化率、温度边界与出口压力；Gibbs：指定物种集、HYSYS热力学数据、无固体碳。
- 从 HYSYS 读回湿基摩尔分数、kmol/h、K、kPa、kW；组分名称与分子式对照HYSYS数据库；流量、元素/转化率/出口边界独立校验。
- 四组案例均真实求解并保存、重开后 CalcLevel=500。实机故障测试：未知组分生成阶段诊断，求解和校验不标成功。
- 全局文件锁保护会话；独立子进程STA，超时有界并明确要求检查HYSYS残留计算。

证据：`docs/evidence/*.json`包含实际输入版本、模型决策/审计、COM结果；本机`.hsc`位于对应记录case_path。API模型选型和固定类型Adapter集成测试分别记录。案例创建、求解收敛、工程校验是三个独立字段。

## 限制与未完成验证

- 仅验证PR物性包、气相单反应Conversion、指定物种Gibbs。不支持任意脚本、任意COM对象或模型自写代码执行。
- Equilibrium可以创建，但`LnKSource`设置与读回不一致，来源含义尚未验证，因此不广告该能力。CSTR/PFR动力学、多条conversion、固相/电解质、动态过程未实测。
- 早期打开安装样例出现E_ACCESSDENIED且载入副作用；新建Agent案例重开已成功，样例结果从未作为本系统求解证据。
- CalcLevel=500加已知/一致输出是自动化收敛判据，不是实际工厂安全设计批准；工程校验只覆盖当前已实现检查。
- 原始考核提示的“无固定反应器类型”以反应和数据条件理解；Gibbs适配本次已确认数据，不将两个温度或场景名硬编码到该选择。
