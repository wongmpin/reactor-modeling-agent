# Live Demo 与两个必测场景录屏操作单

视频由用户录制；本项目提供可运行界面、脚本、结果和证据，不生成视频。所有测试异构体比例/运行小时等假设必须在录屏中由用户明确确认。

## 录制前

1. 在项目目录运行 `scripts/setup.ps1`；确保 `.env` 已有Key且不会进入画面。
2. 运行 `.venv/Scripts/python.exe -m reactor_agent.cli model-check`，确认API/JSON/工具往返成功；偶发API空JSON会有界重试并保留失败诊断。
3. `hysys-check`核对V15与支持清单。运行普通测试；条件允许时设置`RUN_HYSYS_INTEGRATION=1`运行实机测试。
4. `scripts/start.ps1`启动UI、MCP和队列消费者，打开输出URL。关闭无关通知，检查`data/cases`可写。
5. 检查三种状态：案例已保存、求解已收敛、工程校验通过；不能仅凭保存案例显示成功。

## 视频一：重整温度比较（建议5-7分钟）

先输入原始需求：

> 甲烷蒸汽重整，甲烷与水蒸气摩尔比1:2.7。CH4+H2O生成CO+3H2；CO+H2O生成CO2+H2。进料520°C，压力13.5bar，比较出口710°C和600°C的组分分布。请提出可确认的年处理量与年运行小时，流量合理。不要假设动力学、平衡常数。

展示模型选型解释与缺参问题。在聊天输入框连续回答问题；对话中的假设卡片可逐项勾选，再点“确认所选假设”；缺参时“开始真实模拟”禁用。可随时提问解释，助手回答时不修改规格。若接受以下演示边界，可明确回复：

> 本次演示确认：甲烷年处理量100000t/a、8000h/a，即甲烷12500kg/h；水蒸气与甲烷摩尔比2.7，总流量由HYSYS组分分子量计算（本机约2882.895kmol/h）。进料520°C、13.5bar，无压降。先算出口710°C，温度指定模式，物性采用Peng-Robinson。确认使用HYSYS V15纯组分热力学数据库，物种全集限CH4/H2O/CO/CO2/H2，排除固体碳。本次仅计算这些物种的热力学平衡分布，不给动力学、Ka或反应Gibbs能数值。请按数据条件独立选型，并说明限制。

- 展示模型选择，不能手动绕过或硬编码成Gibbs。若模型选择当前不支持的反应器，应展示诊断，补充缺失信息后让模型重新判断。
- 点击“开始真实模拟”，等待运行结果自动加入对话；显示V15版本、三个状态、湿基组分、案例下载和热负荷。
- 在同一对话输入“保留其余条件，出口温度改为600°C”，生成新版本并重新选型/运行。
- 展示两版本结果：710°C测试H2约0.40639、CH4约0.09614；600°C测试H2约0.27018、CH4约0.16171。对比方向和物理解释，不把平衡值当实际催化炉设计保证。
- 保存两个运行JSON与`.hsc`，可在HYSYS重开“Agent Reactor”和物流。

## 视频二：甲苯歧化与选择性澄清（建议4-6分钟）

点击左侧“＋ 新建对话”，输入：

> 纯甲苯10000kg/h，380°C、2.5MPa，甲苯转化率50%，不研究动力学、不考虑副反应。2C7H8生成C6H6和C8H10，二甲苯需要邻、间、对三种异构体。请模拟出口组成。

- 展示系统询问异构体选择性。计量式只确定苯与二甲苯总量，不确定异构体比例。
- 如果愿意使用集成测试假设，亲自确认：“仅为演示假设，邻/间/对二甲苯摩尔选择性0.2/0.5/0.3；气相，以甲苯为基准50%转化率，Peng-Robinson，出口380°C、25bar，无压降。”也可提供自己的分布，系统据此建模。
- 展示模型选择Conversion的依据、规格中的加权计量和明确假设，再提交运行。
- 检查物料/元素守恒、50%转化率、出口组成。上述测试分布对应甲苯0.5、苯0.25、o/m/p=0.05/0.125/0.075；这些值只是实机验证参考，应用不会返回预设值。
- 在对应结果的“运行详情与文件”下载案例/JSON；展开“当前条件与诊断”及“对话、规格和审计导出”。

## Live Demo 通用性与失败（建议3分钟）

- 新任务输入乙烯与氢气各50kmol/h、150°C、10bar、乙烯转化40%，无动力学；确认PR、出口150°C、无压降、气相基准乙烯。展示同一链路选型与真实运行。
- 另开任务仅输入“做乙醇脱水”，展示缺参暂停，不继承上个任务进料。
- 错误场景：不守恒计量式先被Harness拒绝；未知HYSYS组分产生阶段错误，求解/校验不标成功；未提供动力学的PFR需求不会被校验器静默改成Conversion。

## 关闭与恢复

运行`stop.ps1`只停止本项目进程树，HYSYS本体保留。关闭前等队列空闲。异常关闭后重启消费者只恢复已过期的运行记录，最多两次；超时后先检查HYSYS残留求解，不能盲目自动重试。
